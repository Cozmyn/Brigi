# Artist assets

Place approved photography here and set paths in `src/lib/site.ts` → `siteContent.photos`.
Suggested names: hero.webp, landscape.webp, live.webp, portrait.webp, stage.webp,
atmosphere.webp, editorial.webp, social.jpg. Empty sources display abstract stage artwork;
this artwork does not represent Brigitta. Use genuine photos and useful Romanian alt text.
Recommended: hero 1600×2000, landscape/live 1800×1200, portrait 1200×1600, social 1200×630.
Images should be compressed WebP/AVIF, with important faces away from crop edges.
